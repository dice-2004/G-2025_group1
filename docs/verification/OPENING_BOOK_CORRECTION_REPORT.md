## 🎯 修正内容

### 修正1: 手動定石にゲームIDを付与

#### Before（論理的問題あり）

```csv
# Gomoku Opening Book
# Format: move_number,x,y,comment
#
1,7,7,初手は中央
2,8,8,黒の斜め
2,8,7,黒の横
2,7,8,黒の縦
3,6,6,白の対角
3,8,6,白の攻撃
3,6,8,白の守備
```

**問題点**:
- ❌ ゲームIDがない → ゲーム単位選択が機能しない
- ❌ 手順の整合性が不明 → 戦略的意味が曖昧
- ❌ 学習システムとの不整合 → 混在時の動作が不明確

#### After（修正済み）

```csv
# Gomoku Opening Book v2.0
# ========================================
# ゲームID規則:
#   game 1～999: 学習定石（自動生成）
#   game 101～199: 手動定石（基本パターン）
#   game 201～299: プロの定石（標準パターン）
# ========================================

# Game 101: 斜め攻撃定石
1,7,7,Manual: 斜め攻撃 (game 101)
2,8,8,Manual: 斜め攻撃 (game 101)
3,6,6,Manual: 斜め攻撃 (game 101)
4,9,9,Manual: 斜め攻撃 (game 101)
5,5,5,Manual: 斜め攻撃 (game 101)

# Game 102: 横展開定石
1,7,7,Manual: 横展開 (game 102)
2,8,7,Manual: 横展開 (game 102)
3,6,7,Manual: 横展開 (game 102)
4,9,7,Manual: 横展開 (game 102)
5,5,7,Manual: 横展開 (game 102)

# Game 103: 縦展開定石

2,7,8,Manual: 縦展開 (game 103)

4,7,9,Manual: 縦展開 (game 103)
5,7,5,Manual: 縦展開 (game 103)
```

**改善点**:
- ✅ 各ゲームが5手の完全なシーケンス
- ✅ ゲームIDで明確に識別可能
- ✅ 手順の整合性が保証される

│  - 花月、浦月など伝統的な定石        │
│  - 例: "Pro: 花月 (game 201)"        │

## 📝 使用方法

### 基本的な使用

```bash
# ビルド
cmd /c build.bat

# 実行
gomoku_new.exe
```

**自動的な動作**:
1. 11種類の定石から1つをランダム選択
2. 選択されたゲームの手順を一貫して使用
3. 5手目まで定石を使用

### 学習モードでの使用

```
config.txt:
LEARNING_MODE=PRACTICE
```

**動作**:
1. 対局を実行
2. 勝利した場合、最初の5手を追加
3. `game 1～999` の範囲で自動的にゲームIDが割り当て
4. 次回以降、新しい定石が候補に追加
