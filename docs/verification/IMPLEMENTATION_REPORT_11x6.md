## 🎓 学んだこと

### 抽出と窓の違い
- **抽出**: データを取り出す範囲（広め）
- **窓**: 抽出したデータ内で評価する範囲（狭め）
- **必要条件**: 窓 < 抽出（両側の情報確認のため）

### スライディングウィンドウの重要性
- 1つの窓だけでは不十分
- 複数の窓で評価することで、多様なパターンを検出
- 同じ石が複数の窓で異なる評価を受ける可能性

### 五目並べに最適な窓サイズ
- **5マス窓**: 基本パターンのみ、開いた四は検出困難
- **6マス窓**: 開いた四を検出可能、バランス良い ✅
- **8マス窓**: 複雑なパターンも検出可能だが、評価コスト高い
- **9マス窓**: スライディング不可、両側確認不可 ❌
