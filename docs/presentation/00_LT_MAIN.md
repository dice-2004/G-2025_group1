## ⚡ スライド4: 技術的工夫② - TSS + Alpha-Beta (3:00-4:00)

### TSS（Threat Space Search）

**詰み筋を線形時間O(n)で発見**

#### Priority（優先度）システム
```
Priority 1: 自分の5連 → 即勝利
Priority 2: 相手の5連防御 → 必須
Priority 3: 開いた四 → 次確実
Priority 4: 相手の脅威防御 → 重要
Priority 5: 攻撃的な手 → 有利
```

#### 効果
- **計算量**: O(225) = 全マスチェック
- **処理時間**: 約1-5ms
- **高速化率**: Alpha-Betaの**200-1000倍**

### Alpha-Beta枝刈り

**不要な探索を大幅削減**

#### 基本原理
```python
def alpha_beta(depth, alpha, beta, is_max):
    if depth == 0: return evaluate()
    
    if is_max:
        for move in legal_moves:
            score = alpha_beta(depth-1, alpha, beta, False)
            alpha = max(alpha, score)
            if beta <= alpha: break  # β枝刈り
        return alpha
```

#### 効果
| 深度 | Minimax | Alpha-Beta | 削減率 |
|------|---------|-----------|--------|
| 4 | 6,250,000 | 25,000 | **99.6%** |
| 6 | 15.6億 | 5,000,000 | **99.7%** |

## 📝 質疑応答用メモ

### よくある質問と回答

**Q1: なぜ五目並べを選んだ？**
A: 囲碁・将棋より単純だが、十分に深い戦略性がある。学習システムの効果を検証しやすい。

**Q2: 学習にどれくらい時間がかかる？**
A: 1試合約2-5分。10試合で効果が見え始め、100試合で安定。

**Q3: 人間に勝てる？**
A: 初心者には勝てる。中級者とは互角。上級者にはまだ及ばない。

**Q4: AlphaZeroとの違いは？**
A: AlphaZeroは深層学習+MCTS。本プロジェクトは伝統的AI+パラメータ学習。軽量で実装しやすい。

**Q5: 他のゲームに応用できる？**
A: 可能。盤面表現と評価関数を変えれば、オセロ・将棋などに応用可能。

**Q6: 置換表のヒット率は？**
A: 序盤20-30%、中盤40-60%、終盤60-80%。

**Q7: 禁じ手の判定は？**
A: 黒石のみ適用。三三・四四・長連を.libgomoku_to.cの関数で判定。

**Q8: 最大メモリ使用量は？**
A: 約4.1MB。非常にコンパクト。

**Q9: 開発期間は？**
A: （実際の期間を記入）

**Q10: 一番苦労した点は？**
A: 学習システムの調整。学習率や調整タイミングの最適化に試行錯誤。
