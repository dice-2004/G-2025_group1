# プロジェクト概要

このドキュメントでは、五目並べAI v3.4の全体像、主要機能、技術的特徴について説明します。

---

## 🎯 プロジェクトの目的

**対戦するほど強くなる学習型五目並べAI**の開発

このプロジェクトは、単なる五目並べAIではなく、対戦データから学習し、自動的に強化される学習システムを備えた高性能AIです。

---

## ✨ 主要機能

### 探索・評価機能

| 機能 | 説明 |
|-----|------|
| **ビットボード** | 効率的な盤面表現 |
| **Alpha-Beta探索** | 探索の枝刈りによる高速化 |
| **置換表（Zobrist Hashing）** | 探索結果のキャッシュ（2-5倍高速化） |
| **序盤定石** | データベース化された序盤手順 |
| **20種類の評価パターン** | 複合・飛び・位置評価パターン |
| **11マス抽出 + 6マス窓** | 精密な局面評価 |
| **TSS（詰み探索）** | 必勝手順の探索 |
| **禁じ手判定** | 五目並べルールの完全実装 |

### 学習・デバッグ機能

| 機能 | 説明 |
|-----|------|
| **学習システム** | パターンスコアの自動調整 |
| **学習モード切替** | PRACTICE（学習中）/ PRODUCTION（本番） |
| **CSV設定ファイル** | 外部からの設定変更が可能 |
| **デバッグ機能** | 4段階のデバッグレベル（0-3） |
| **Iterative Deepening** | 時間制限への柔軟な対応 |
| **時間管理機能** | 探索時間の最適化 |
| **探索統計表示** | 探索ノード数、置換表ヒット率など |

## 🏆 技術的特徴

### 高速化技術

1. **ビットボード表現**
   - 盤面を64bitデータで表現
   - ビット演算による高速処理

2. **置換表**
   - Zobrist Hashingによる盤面のハッシュ化
   - 探索結果のキャッシュで2-5倍の高速化

3. **Alpha-Beta枝刈り**
   - 不要な探索枝を大幅にカット
   - 理論的には探索ノード数を√n に削減

### 精密な評価関数

1. **20種類の評価パターン**
   ```
   基本パターン（8種類）
   ├── 五、開いた四、四、開いた三
   ├── 三、開いた二、二、一

   複合パターン（3種類）
   ├── 四四、四三、三々

   飛びパターン（3種類）
   ├── 飛び四、飛び三、飛び二

   位置評価（6種類）
   └── 中央評価、連結評価、敵石近接評価など
   ```

2. **11マス抽出 + 6マス窓**
   - 中心石から前後5マスずつ抽出（計11マス）
   - 6マス窓をスライドさせて多角的に評価
   - 「開いた四」を正確に検出可能

### 学習システム

1. **勝敗分析**
   - 各試合の結果を記録
   - 勝率を計算

2. **パターン評価**
   - 使用したパターンを分析
   - 効果的なパターンを特定

3. **スコア調整**
   - 勝率に応じて評価値を最適化
   - 段階的な強化学習

4. **定石学習**
   - 勝った手順を記憶
   - opening_book.csvに保存

5. **データ保存**
   - 学習データをファイルに保存
   - 次回起動時に引き継ぎ

## 📊 期待される効果

| 試合数 | 効果 |
|-------|------|
| **5-10試合** | 初歩的なミスが減少 |
| **20-50試合** | 勝率が安定、定石が増加 |
| **100試合以上** | 理論上の最適値に収束 |

## 🔧 アーキテクチャ

### モジュール構成

```
五目並べAI
├── ゲームインターフェース（gomoku.c/h）
│   └── ユーザー入出力、盤面表示
│
├── AIエントリポイント（gomoku_ai.c/h）
│   └── AI思考エンジンへの橋渡し
│
├── 設定管理（config.c/h）
│   └── CSV設定ファイルの読み込み
│
└── AI思考エンジン（logics/）
    ├── main_engine.c/h      ← Alpha-Beta、ID実装
    ├── evaluation.c/h       ← 評価関数（20パターン）
    ├── transposition.c/h    ← 置換表
    ├── opening_book.c/h     ← 序盤定石
    ├── learning.c/h         ← 学習システム
    ├── TSS.c/h              ← 詰み探索
    └── debug_utils.c/h      ← デバッグユーティリティ
```
