## ✅ 実装した機能

### 1. ⏱️ 時間切れ時の結果巻き戻し機能

**実装内容**:
```c
// 前の深度の結果を保持
int prev_x = -1, prev_y = -1, prev_score = 0;

// 探索完了後に時間チェック
if (探索時間 > 制限時間) {
    // この深度の結果を破棄
    *best_x = prev_x;      // 前の結果に戻す
    *best_y = prev_y;
    best_score = prev_score;
    break;
}
```

**動作**:
- ✅ 制限時間を超えた場合、その深度の結果を**破棄**
- ✅ ひとつ前の**完了した深度の結果**を返す
- ✅ 不完全な結果を使わない

**例**:
```
深度1: 完了 (50ms) ✅
深度2: 完了 (250ms) ✅
深度3: 完了 (1,750ms) ✅
深度4: 完了 (6,750ms) ✅
深度5: 完了したが時間切れ (14,750ms) ❌ → 破棄

→ 深度4の結果を返す ✅
```

### 2. 🎚️ 簡単に切り替えられる設定

**config.txt に新設定を追加**:
```txt
# Iterative Deepening 時間制限閾値（0.0～1.0）
# この値 × TIMEOUT_MS の時間までに深度探索を開始します
# 例: 0.7 = 70%の時点で次の深度に進まない
#     0.8 = 80%の時点で次の深度に進まない（推奨）
#     0.9 = 90%の時点で次の深度に進まない（積極的）
# 注意: 探索中に時間切れになった場合、その深度の結果は破棄され、
#       前の深度の結果が返されます
ID_TIME_THRESHOLD=0.8
```

**切り替え方法**:
1. `config.txt` を編集
2. `ID_TIME_THRESHOLD` の値を変更（0.0～1.0）
3. 保存してゲームを起動

**推奨値**:
| 値 | 特徴 | 推奨シーン |
|---|------|----------|
| 0.7 | 保守的 | 大会・本番環境 |
| **0.8** | **バランス型（推奨）** | **通常の対戦** |
| 0.9 | 積極的 | 練習・深い探索 |

## 🎓 技術的ハイライト

### 改善点

1. **結果の保持**
   ```c
   // 探索成功後、前の結果を保存してから更新
   prev_x = *best_x;
   prev_y = *best_y;
   prev_score = best_score;

   *best_x = temp_x;
   *best_y = temp_y;
   best_score = score;
   completed_depth = depth;
   ```

2. **時間切れ検出**
   ```c
   if (elapsed > time_limit) {
       printf("[ID] Time limit exceeded during depth %d search.\n", depth);
       printf("[ID] Discarding depth %d result, returning depth %d result.\n",
              depth, completed_depth);

       // 前の結果に戻す
       *best_x = prev_x;
       *best_y = prev_y;
       best_score = prev_score;
       break;
   }
   ```

3. **閾値の活用**
   ```c
   double threshold = g_config.id_time_threshold;

   // 探索開始前のチェック
   if (elapsed > time_limit * threshold) {
       printf("[ID] Time threshold reached, stopping before depth %d.\n", depth);
       break;
   }
   ```
