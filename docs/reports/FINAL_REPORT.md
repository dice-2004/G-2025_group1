## 💡 技術的なハイライト

### 1. gomoku.c未変更の実現

**課題**: メインプログラムを変更せずに学習機能を実装

**解決策**:
```c
// 差分検出による手の記録
static int g_previous_board[BOARD_SIZE][BOARD_SIZE];

void detect_and_record_new_moves(const int board[][BOARD_SIZE]) {
    for (int y = 0; y < BOARD_SIZE; y++) {
        for (int x = 0; x < BOARD_SIZE; x++) {
            if (board[y][x] != STONE_SPACE &&
                g_previous_board[y][x] == STONE_SPACE) {
                record_move(x, y, board[y][x]);
            }
        }
    }
}

// 遅延勝敗判定
if (move_count == 0 && g_previous_move_count > 0) {
    int winner = detect_winner(g_previous_board);
    finish_game_record(result);
}
```

### 2. 学習アルゴリズム

**パターンスコア更新式**:
```
新スコア = 現スコア + (調整値 × 学習率 × 勝敗係数)
学習率 = 0.05 / sqrt(総試合数)
```

**効果**:
- 初期: 大きく変化 (速く学習)
- 後期: 小さく変化 (安定化)
- 過学習を防止

### 3. 置換表による高速化

**Zobrist Hashing**:
```c
// O(1)での同一局面判定
uint64_t hash = 0;
for each stone:
    hash ^= zobrist_table[x][y][color];
```

**効果**:
- 探索速度: 2-5倍向上
- ヒット率: 40-70%
- メモリ: 4MB (262,144エントリ)
