## 🗂️ カテゴリ分類の基準

### 📘 guides/（ガイドドキュメント）
**基準**: ユーザーが機能を使うためのガイド、設定方法の説明

**含まれるドキュメント**:
- システム動作ガイド
- 各機能の使い方
- 設定ファイルの説明
- ビルド方法

### 📗 technical/（技術ドキュメント）
**基準**: アルゴリズム、データ構造、実装の技術的詳細

**含まれるドキュメント**:
- 完全技術資料
- AI実装の詳細
- 学習システムの技術解説

### 📙 verification/（検証・最適化レポート）
**基準**: 最適化の試行、検証、分析の記録

**含まれるドキュメント**:
- 窓サイズ分析
- 最適化試行の詳細
- 正確性の検証
- 復元の経緯

### 📕 reports/（実装検証・報告書）
**基準**: 実装完了報告、バージョン別の成果記録、修正レポート

**含まれるドキュメント**:
- 実装検証レポート
- バージョン別完了報告
- 修正・メンテナンスレポート

### 📕 quickstart/（クイックスタート・プレゼン）
**基準**: すぐに始めるための情報、概要説明

**含まれるドキュメント**:
- クイックスタートガイド
- プレゼンテーション資料

## 📊 ナビゲーション構造

### 3層構造

```
プロジェクトルート（README.md）
    ↓
    ├─ クイックスタート
    ├─ カテゴリ一覧
    ├─ 目的別ナビゲーション
    └─ ドキュメントトップ（docs/README.md）
        ↓
        ├─ 全カテゴリの概要
        ├─ レベル別学習パス
        ├─ 検索のヒント
        └─ 各カテゴリREADME（guides/README.md など）
            ↓
            ├─ カテゴリの説明
            ├─ ドキュメント一覧
            ├─ 読む順番
            └─ 個別ドキュメント
```

### 導線の種類

1. **トップダウン**: プロジェクトルート → docs → カテゴリ → ドキュメント
2. **目的別**: 目的 → 推奨ドキュメント
3. **レベル別**: スキルレベル → 学習パス → ドキュメント
4. **カテゴリ横断**: 関連リンクで他のカテゴリへ移動
