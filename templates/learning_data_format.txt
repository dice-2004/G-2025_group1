================================================================================
learning_data.dat フォーマット説明
================================================================================

ファイル名: learning_data.dat
形式: バイナリ
場所: 実行ファイルと同じディレクトリ

================================================================================
【1】概要
================================================================================

learning_data.dat は、AIが学習した内容を保存するバイナリファイルです。
このファイルには以下の情報が含まれます：

1. 調整されたパターン評価値（20種類）
2. 対戦統計（総ゲーム数、勝敗数、勝率）
3. 学習した定石（オプション）
4. メタデータ（バージョン、最終更新日時など）


================================================================================
【2】ファイル構造（バイナリレイアウト）
================================================================================

Total Size: 約128バイト～（定石データにより変動）


================================================================================
【3】データの意味
================================================================================

● Magic Number (0x474F4D41):
  ファイルの正当性を確認するための識別子
  "GOMA" のASCIIコードに相当

● Format Version:
  ファイルフォーマットのバージョン番号
  将来の拡張に対応

● Last Modified Timestamp:
  最後に学習データを保存した日時（Unix時間）

● Pattern Scores:
  各パターンの評価値（学習により調整された値）
  初期値から +/- されていく

● Learning Statistics:
  - Total Games: 総対戦数
  - Wins: 勝利数
  - Losses: 敗北数
  - Draws: 引き分け数
  - Win Rate: 勝率（Wins / Total Games）

================================================================================
【5】ファイルの読み書き
================================================================================

● 読み込み（AI起動時）:
  1. ファイルの存在確認
  2. Magic Numberの検証
  3. Format Versionのチェック
  4. パターンスコアを読み込み → グローバル変数に設定
  5. 統計情報を読み込み → LearningStats構造体に設定

● 書き込み（対戦終了時、AI終了時）:
  1. 現在のパターンスコアを取得
  2. 統計情報を更新
  3. Timestampを現在時刻に設定
  4. バイナリ形式でファイルに書き込み
  5. ファイルを閉じる


================================================================================
【6】エラーハンドリング
================================================================================

● ファイルが存在しない:
  → 初回起動と判断、初期値を使用

● Magic Numberが不正:
  → ファイル破損と判断、初期値を使用、警告表示

● Format Versionが異なる:
  → 互換性チェック、可能なら変換、不可能ならエラー

● ファイルサイズが不正:
  → ファイル破損と判断、初期値を使用

● 書き込みエラー:
  → ディスク容量不足やアクセス権限の問題、エラー表示


================================================================================
【7】手動でのデータ確認方法
================================================================================

Windowsの場合:
  コマンドプロンプトで以下を実行:
  > certutil -encodehex learning_data.dat learning_data.hex
  または
  > format-hex learning_data.dat  (PowerShell)

Linux/Macの場合:
  ターミナルで以下を実行:
  $ hexdump -C learning_data.dat
  または
  $ xxd learning_data.dat


================================================================================
【8】データのリセット方法
================================================================================

学習データをリセットしたい場合:
  1. learning_data.dat を削除
  2. AIを再起動
  → 自動的に初期値から再スタート

または:
  1. LEARNING_MODE を PRACTICE に設定
  2. AIで練習対戦を繰り返す
  3. 新しい学習データが蓄積される


================================================================================
【9】バックアップ方法
================================================================================

学習データのバックアップ:
  1. learning_data.dat をコピー
  2. 日付付きで保存
     例: learning_data_20250101.dat

復元:
  1. バックアップファイルを learning_data.dat にリネーム
  2. AIを再起動


================================================================================
【10】まとめ
================================================================================

learning_data.dat は、AIの「記憶」を保存する重要なファイルです。

● 自動的に生成・更新される
● 対戦を重ねるごとに内容が変化
● バイナリ形式で効率的に保存
● 破損時は自動的に初期値にリセット
● バックアップ＆復元が可能

このファイルにより、AIは前回の学習内容を引き継ぎ、
継続的に成長することができます。
